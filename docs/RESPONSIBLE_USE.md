# Responsible Use

Proyek hanya untuk akun/perangkat sendiri, penerima yang menyetujui, komunikasi internal sah, dan penelitian interoperabilitas yang mematuhi hukum.

Tidak diterima: spam, blast tanpa persetujuan, scraping nomor/anggota grup, account farming, account warm-up, anti-ban, ban evasion, bypass rate limit, fingerprint spoofing, CAPTCHA bypass, session hijacking, token/credential theft, eksploitasi perangkat, atau pengumpulan data pribadi tanpa izin.

Integrator wajib menerapkan consent record, unsubscribe process, rate limit bisnis, retention policy, dan audit log.
