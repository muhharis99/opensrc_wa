# Contributing

Kontribusi harus mematuhi kebijakan clean-room dan responsible use.

1. Buat issue yang menjelaskan masalah atau bukti interoperabilitas.
2. Jangan menyertakan source code, komentar, schema, fixture, atau key material dari proyek lain tanpa izin dan provenance yang jelas.
3. Tambahkan unit test, malformed-input test, boundary test, dan dokumentasi status.
4. Jalankan `pnpm validate` sebelum mengirim perubahan.
5. Jangan mengubah fitur menjadi `LIVE_TESTED` tanpa bukti pengujian nyata menggunakan akun/perangkat sendiri.
6. Jangan commit secret, nomor nyata, QR aktif, private key, credential, atau isi pesan pengguna.
