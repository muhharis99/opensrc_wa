# Changelog

## 0.1.0 - 2026-08-02

- Inisialisasi monorepo TypeScript strict.
- Menambahkan core state machine, typed events, retry, idempotency, dan deduplication.
- Menambahkan transport abstraction, protocol research codec, dan request correlation.
- Menambahkan AES-256-GCM crypto provider, encrypted file store, dan SQLite store.
- Menambahkan mock pairing, mock message pipeline, REST API, WebSocket events, CLI, webhook HMAC, observability, Docker, CI, dokumentasi, serta contoh PHP.
- Menandai konektivitas protokol live sebagai `BLOCKED`.
