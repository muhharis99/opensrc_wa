# Security Policy

## Supported versions

Versi `0.1.x` adalah bootstrap eksperimental. Belum ada jaminan kompatibilitas protokol live.

## Melaporkan kerentanan

Jangan membuka issue publik yang memuat API key, session material, QR payload, token, private key, nomor telepon, atau data pesan. Gunakan GitHub private vulnerability reporting pada repository apabila tersedia.

Sertakan dampak, langkah reproduksi aman, versi commit, dan mitigasi yang disarankan. Jangan menguji terhadap akun/perangkat yang bukan milik Anda.

## Batas pengujian

Pengujian tidak boleh melakukan spam, bypass pembatasan, eksploitasi akun, credential theft, session hijacking, scraping data pribadi, atau pengiriman tanpa persetujuan.
