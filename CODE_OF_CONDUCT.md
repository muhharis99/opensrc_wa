# Code of Conduct

Komunitas ini mengutamakan diskusi teknis yang hormat, aman, dapat diverifikasi, dan tidak merugikan pengguna lain. Pelecehan, doxing, penyalahgunaan akun, permintaan bypass keamanan, dan publikasi credential dilarang.

Maintainer dapat menolak kontribusi yang tidak memiliki provenance, melanggar lisensi, memfasilitasi spam, atau mengklaim hasil live tanpa bukti.
